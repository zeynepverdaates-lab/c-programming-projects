# C Programming Projects & Practices

This repository contains a collection of fundamental C programming concepts, basic algorithms, core practice exercises, and beginner-level command-line (CLI) applications developed during my learning process.

---

## 📌 Contents & Highlights

The repository covers key foundational topics and mini-projects:

- **Fundamentals & Core Concepts:**
  - Control flow (loops, conditional logic, functions)
  - Array operations and string manipulation
  - Pointer basics and memory management
- **Mini-Projects:**
  - **Phonebook Application:** A command-line contact management tool featuring basic CRUD operations and file handling (`FILE` I/O) to persist data.
  - **ATM / Bank Management System:** A console-based banking application simulating core financial operations such as deposit, withdrawal, balance inquiry, and PIN authentication.

---

## 🛠️ Built With

- **Language:** C (C99 / C11)
- **Compiler:** GCC / Clang
- **Version Control:** Git & GitHub

## 🚀 How to Build and Run

To run any of the source files locally, make sure you have a C compiler installed (e.g., GCC).

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/c-programming-projects.git](https://github.com/your-username/c-programming-projects.git)
   cd c-programming-projects

2. **Compile the source code:**
   ```bash
   gcc main.c -o program

3.**Execute the compiled program:**

- **Linux / macOS:**
  ```bash
  ./program

- **Windows:**
  ```bash
  program.exe
